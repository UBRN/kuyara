# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub:
[Report a vulnerability](https://github.com/UBRN/kuyara/security/advisories/new).
Do not open a public issue or pull request for a security problem.

If you cannot use GitHub, email the address on the [support page](https://ubrn.github.io/kuyara/support).

Include what you found, how to reproduce it and what an attacker could do with it. You will
get an answer as soon as possible, and good-faith reports are welcome.

## Scope

- The kuyara iOS app
- The kuyara Worker API
- The website at https://ubrn.github.io/kuyara/

Out of scope: denial of service by request volume, findings in third-party services
(Apple, Google, Supabase, Cloudflare, PostHog, Expo) themselves, and reports that only list
public identifiers such as the Supabase publishable key, the PostHog project key or the
Worker URL, which are public by design.

Please do not access or change other people's data, and do not run automated scans against
the live API.
