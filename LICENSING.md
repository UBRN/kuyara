# Licensing

kuyara is **source-available**, not open source. The source is public so it can be read,
inspected, and learned from, but commercial use is not granted by the licence.

## Current licence

published by the PolyForm Project at
<https://polyformproject.org/licenses/noncommercial/1.0.0>.

Under it you may use, modify, and redistribute kuyara for any noncommercial purpose,
which the licence defines to include personal study, hobby projects, research,
experiment, and testing, as well as use by charitable, educational, public research,
public safety or health, environmental, and government organisations. Read the licence
itself for the terms that actually bind; this page is a summary and does not modify it.

## Commercial use

Commercial use requires separate written permission or a commercial licence from the
copyright holder. Ask, rather than assuming the answer is no: the restriction exists so
that commercial use is a conversation, not so that it is forbidden.

Contact: the maintainer, through <https://github.com/UBRN/kuyara>.

## Why not open source

The OSI definition of open source forbids restricting fields of endeavour, so a licence
that reserves commercial use cannot be called open source. kuyara does reserve it, so the
project describes itself as source-available instead. The reasoning is recorded in
[ADR 0024](docs/adr/0024-relicensing-to-polyform-noncommercial.md).

## Earlier versions remain MIT

kuyara was MIT licensed from the repository's creation on 2026-07-25 until 2026-09-04.

**That grant is not revoked and cannot be.** Every version distributed under MIT stays
under MIT, and everyone who obtained one of those versions keeps every right MIT gave
them for it, commercial use included. The licence change is forward-looking: PolyForm
Noncommercial governs this version and every later one.

The historical MIT text is in the Git history and is reachable at any commit up to and
including `3b2586a`.

## Ownership

Every commit in this repository is authored by the maintainer; there are no third-party
contributions, no `Co-authored-by` trailers, and no outside pull requests. That is what
made the relicensing possible without contributor consent. See
[ADR 0024](docs/adr/0024-relicensing-to-polyform-noncommercial.md).
